# T³：Reducing Belief Deviation in Reinforcement Learning for Active Reasoning of LLM Agents

> 阅读对象：Deyu Zou 等，ICLR 2026 Oral，arXiv v2（2026-03-03）。方法名为 **T³（Truncating Belief-Trapped Trajectories）**。

## 1. 一句话总结

T³ 不改 PPO/GRPO/GSPO 的损失函数，而是在 rollout 阶段检测“认知进展是否持续停滞”：一旦轨迹进入 **Belief-Trap Region（BTR，信念陷阱区域）**，就截断其无信息的尾部，只把仍然有信息量的前缀交给 RL 优化器。

\[
\boxed{
\text{partial observability}
\;\rightarrow\;
\text{belief deviation}
\;\rightarrow\;
\text{uninformative tail / credit contamination}
\;\rightarrow\;
\text{proxy detection + early truncation}
}
\]

核心不是增加一个中间奖励，而是改变**哪些交互步骤参与优势估计和策略更新**：保留探索前缀，删除进入信念陷阱后的重复、无关或循环动作。

## 2. 问题与核心直觉

### 2.1 Active reasoning 的困难

在主动推理任务中，LLM agent 需要多轮向环境提问、获得反馈，再根据反馈更新对隐藏状态的判断。例如：

- 猜数字：每次猜测都应缩小候选数字集合；
- 电路识别：每次查询都应排除一部分候选电路；
- 情境谜题：问题应逐渐约束可能的故事解释；
- 偏好估计：比较电影后应逐步修正用户偏好向量。

这类任务与普通单轮生成不同：动作本身既是决策，也是获取信息的实验。LLM 并没有显式、可靠的 Bayesian belief filter，随着交互变长，可能出现：

- 忘记之前的反馈，提出违反已有约束的问题；
- 重复同一个问题或反复访问同一信息子目标；
- 对连续偏好向量的估计停滞甚至发散；
- 在错误的内部状态上继续行动，形成无效循环。

### 2.2 为什么完整轨迹会伤害 RL

论文研究的是 outcome-based RL：通常只有最后一步有奖励。若轨迹前半段曾经做出有价值的探索，但后来进入 BTR，后半段会变成很长的无信息尾部。GAE/return 会把尾部的负面信号反向传播给早期动作，于是：

1. 有价值的探索动作被错误地判为低优势甚至负优势；
2. 策略更新抑制真正应该保留的探索行为；
3. rollout token 被浪费在无法恢复的循环中；
4. 训练曲线出现高方差、坍塌或早熟收敛。

T³ 的判断是：**在 BTR 入口处停止，比让优化器继续学习整条被污染的轨迹更好。**

### 2.3 T³ 与常见方法的区别

- **不是 reward shaping：** 不人为构造逐步奖励，也不要求给每个 token 重新标注 credit。
- **不是修改 PPO/GRPO/GSPO：** 基础算法、模型结构和 policy loss 保持不变。
- **不是简单截短固定长度：** 截断点由“任务进展停滞”的 proxy 决定。
- **不是直接读取 LLM 的真实 belief：** 真实 belief 与 BTR 只用于理论分析；实践中使用候选集变化、反馈类型、语义重复度或显式状态估计等可观测信号。

## 3. 数学建模

### 3.1 POMDP 与两种 belief update

将主动推理建模为部分可观测决策过程：

\[
(\mathcal S,\mathcal A,\mathcal O,\mathcal T,\mathcal Z,\mathcal R,\gamma),
\]

其中 \(s\in\mathcal S\) 是不可见的真实状态，\(a_t\in\mathcal A\) 是问题/查询动作，\(o_t\in\mathcal O\) 是环境反馈，\(\mathcal Z(o\mid s,a)\) 是观测模型。为便于分析，论文假定一个 episode 内的真实状态 \(s^\star\) 固定。

agent 的 belief \(b_t\in\Delta(\mathcal S)\) 是对隐藏状态的内部分布。论文比较：

1. **oracle reasoner**：使用正确的 Bayesian update；
2. **LLM reasoner**：使用参数化但有误差的内部 update。

oracle 更新为：

\[
b_{t+1}^\star(s)
= B^\star(b_t^\star,a_t,o_t)(s)
= \frac{\mathcal Z(o_t\mid s,a_t)b_t^\star(s)}
{\sum_{s'}\mathcal Z(o_t\mid s',a_t)b_t^\star(s')}.
\]

LLM 的更新写为：

\[
b_{t+1}=B_\theta(b_t,a_t,o_t),
\qquad a_t\sim\pi(\cdot\mid b_t).
\]

理论上可以用

\[
d(b,b')=\sum_{s\in\mathcal S}|b(s)-b'(s)|
\]

衡量 LLM belief 与 oracle belief 的偏离，但实际 LLM 并不显式暴露 \(b_t\)。

### 3.2 Truth-anchored potential

论文用真实状态定义一个只用于理论分析的潜势：

\[
\boxed{\Psi(b):=-\log b(s^\star)}.
\]

性质：

- \(\Psi(b)\ge 0\)；
- \(\Psi(b)=0\) 当且仅当 belief 将全部质量放在真实状态上；
- \(\Psi\) 越小，表示越接近正确状态；
- 高 \(\Psi\) 表示 agent 对真实状态的信念质量很低、偏离严重。

记 \(\Psi_t=\Psi(b_t)\)，\(\Psi_t^\star=\Psi(b_t^\star)\)。oracle 假设最终能够收敛到真实状态，即 \(\Psi_t^\star\to 0\)。

### 3.3 信息增益、实际进展与 update error

对 belief \(b\) 和动作 \(a\)，在正确 Bayesian update 下的一步信息量定义为：

\[
I(b,a)
:= \Psi(b)-\mathbb E_{o\sim\mathcal Z(\cdot\mid s^\star,a)}
\left[\Psi\left(B^\star(b,a,o)\right)\right].
\]

LLM 使用自身 update 时的一步期望进展为：

\[
P_\theta(b)
:=\Psi(b)-\mathbb E_{a\sim\pi(\cdot\mid b),o}
\left[\Psi\left(B_\theta(b,a,o)\right)\right].
\]

LLM 相对 Bayesian update 的误差定义为：

\[
c_\theta(b)
:=\mathbb E_{a\sim\pi(\cdot\mid b),o}
\left[
\Psi\left(B_\theta(b,a,o)\right)
-
\Psi\left(B^\star(b,a,o)\right)
\right].
\]

三者满足关键分解：

\[
\boxed{
P_\theta(b)
=\mathbb E_{a\sim\pi(\cdot\mid b)}[I(b,a)]-c_\theta(b)
}
\]

解释：LLM 的实际进展 = 理想动作的信息价值 − belief update 误差。当 update error 足够大时，即使动作本身有信息，整体进展也会变成非正。

## 4. Belief-Trap Region（BTR）与理论结果

### 4.1 Update-error growth 假设

论文的核心假设是：当 belief 已经偏离到高潜势区域时，更新误差至少线性增长：

\[
\exists m_\theta>0,c_0\ge 0,U_0\ge 0,
\quad
\Psi(b)\ge U_0
\Rightarrow
c_\theta(b)\ge m_\theta\Psi(b)-c_0.
\]

直觉是：模型越不确定/越迷失，后续越难正确解释新反馈，错误会被当前错误状态放大。

理论还使用以下技术条件：

- 观测非退化：可达的 \(\mathcal Z(o\mid s,a)\ge\eta>0\)；
- policy 对 belief 是 Lipschitz 的：
  \[
  \mathrm{TV}(\pi(\cdot\mid b),\pi(\cdot\mid b'))
  \le L_\pi\lVert b-b'\rVert_1;
  \]
- oracle 的潜势最终收敛，且其单步信息量有界。

### 4.2 Theorem 1：高偏离会进入吸收式陷阱

论文给出一个足够阈值。令

\[
\bar B=2\left(-L_\pi\log\eta+\frac1\eta\right),
\qquad
U=\max\left\{U_0,
\frac{\Psi_1^\star+\bar B+c_0}{m_\theta}\right\}.
\]

定义首次越过阈值的时间：

\[
t_S:=\inf\{t:\Psi_t\ge U\}.
\]

若 \(t_S<\infty\)，则从该时刻起：

\[
P_\theta(b_t)\le0,
\qquad
\mathbb E[\Psi_{t+1}\mid b_t]\ge\Psi_t,
\quad t\ge t_S.
\]

也就是说，潜势不再具有期望下降趋势；轨迹进入一个**吸收式的 Belief-Trap Region**。形式化定义为：

\[
\mathcal R_\theta\subseteq\Delta(\mathcal S)
\text{ 是 BTR}
\iff
\mathcal R_\theta \text{ 吸收，且 }P_\theta(b)\le0
\text{（等价于 }\mathbb E[\Psi_{t+1}\mid b_t=b]\ge\Psi(b)\text{）}.
\]

这不是说每个实际 rollout 都必然陷入 BTR，而是说在 update-error growth、oracle 收敛等条件下，一旦越过该充分阈值，继续进展在期望上不再可能。

### 4.3 BTR 进入时间的上界

在更强条件 \(U_0=0\)、且在进入 BTR 前 oracle 潜势满足 \(\Psi_t^\star\ge\mu>0\) 时，令

\[
\Delta_1=\Psi_1-\Psi_1^\star,
\qquad
\delta=m_\theta\mu-(c_0+\bar B)>0,
\]

论文给出：

\[
t_{\mathrm{BTR}}\le t_S
\le
1+\left\lceil
\log_{1+m_\theta}
\frac{m_\theta U+\delta}{m_\theta\Delta_1+\delta}
\right\rceil.
\]

该结果表达了一个重要趋势：在误差随偏离增长的情况下，belief gap 会累积，进入陷阱可能发生在有限步数内。

## 5. 为什么 BTR 会造成 credit assignment 反转

### 5.1 GAE 表示

论文考虑只有终点有非零奖励的 outcome-based RL。GAE 为：

\[
\widehat A_t
=\sum_{j=0}^{T-t-1}(\gamma\lambda)^j\delta_{t+j},
\qquad
\delta_t=r_t+\gamma V_{t+1}-V_t.
\]

如果前缀 \(t<t_S\) 仍然在探索，尾部 \(t\ge t_S\) 却进入 BTR，那么尾部的 value drift 会通过 \((\gamma\lambda)^j\) 影响前缀动作。

### 5.2 Theorem 2：尾部可能反转早期优势

在以下条件下：

1. value function 可写成
   \[
   V_t=g\big(b_t(s^\star)\big),
   \quad g'\ge\kappa_V>0;
   \]
2. 进入 BTR 后，真实状态的 belief mass 平均每一步至少下降 \(\rho_b>0\)：
   \[
   \mathbb E\left[b_{k+1}(s^\star)-b_k(s^\star)\mid\mathcal F_k\right]
   \le -\rho_b,
   \quad k\ge t_S;
   \]

定义前缀与尾部的折扣权重：

\[
S_{\mathrm{pre}}(t)
=\sum_{j=0}^{t_S-t-1}(\gamma\lambda)^j,
\]

\[
S_{\mathrm{tail}}^{\ominus}(t)
=\sum_{j=t_S-t}^{T-t-2}(\gamma\lambda)^j.
\]

则对任意 \(t<t_S\)：

\[
\boxed{
\mathbb E[\widehat A_t]
\le
\gamma\left(
S_{\mathrm{pre}}(t)
-
\kappa_V\rho_b S_{\mathrm{tail}}^{\ominus}(t)
\right)
}
\]

因此只要

\[
\kappa_V\rho_b
>
\frac{S_{\mathrm{pre}}(t)}{S_{\mathrm{tail}}^{\ominus}(t)},
\]

就有 \(\mathbb E[\widehat A_t]<0\)。当 \(\gamma\lambda\to1\) 时，令

\[
\Delta=t_S-t,\qquad L=T-1-t_S,
\]

则近似变为：

\[
\boxed{\kappa_V\rho_b>\frac{\Delta}{L}}.
\]

含义是：尾部越长（\(L\) 越大），或者 BTR 中 belief 退化越快（\(\rho_b\) 越大），就越容易让早期真正有价值的探索动作得到负优势。策略梯度

\[
\nabla J(\theta)
\approx
\mathbb E[\nabla_\theta\log\pi_\theta(a_t\mid s_t)\,\widehat A_t]
\]

因此可能沿错误方向更新，抑制探索。

### 5.3 Corollary：截断可以去掉负向尾部偏差

令 \(\widehat A_t^{\mathrm{pre}}\) 表示在 \(t_S\) 处截断后的优势估计，则：

\[
\boxed{
\mathbb E[\widehat A_t^{\mathrm{pre}}]
\ge
\mathbb E[\widehat A_t]
+
\gamma\kappa_V\rho_bS_{\mathrm{tail}}^{\ominus}(t)
}
\]

理想情况下，截断消除了尾部造成的负向 drift，因而得到更少偏、更低方差的 policy update。这里的结论依赖于“尾部确实已进入 BTR”；如果过早截断仍有信息的轨迹，就会反过来丢掉正向未来回报。

## 6. 从不可观测 BTR 到可执行的 T³ 条件

真实 \(b_t\)、\(s^\star\)、阈值 \(U\) 都不可直接取得，因此论文把“潜势不再下降”替换为可观测的**持续进展停滞**。

令 \(\mathcal H_t\) 表示根据截至时刻 \(t\) 的交互历史仍然可能的假设/解集合，令

\[
d(\mathcal H_t,\mathcal H_{t+1})
\]

表示一步 refinement，例如候选集合减少了多少。T³ 条件是：若在长度为 \(k\) 的窗口内，每一步的进展都不超过阈值 \(\Delta_{\min}\)，就在当前时刻截断：

\[
\boxed{
\forall\tau\in[t-k,t),
\quad
d(\mathcal H_\tau,\mathcal H_{\tau+1})
\le\Delta_{\min}
\quad\Longrightarrow\quad
\text{truncate at }t.
}
\]

对于有限、可枚举且 belief 在候选集上均匀分布的任务：

\[
b_t(s^\star)=\frac1{|\mathcal H_t|},
\qquad
\Psi(b_t)=\log|\mathcal H_t|,
\]

因此“候选空间不再收缩”就是理论潜势不再下降的直接可观测版本。

### 6.1 T³ rollout 流程

```text
for each interaction turn t:
    sample action/query from the current policy
    execute it and receive feedback
    update the task-level progress proxy
    if the last k steps all show insufficient progress:
        stop the rollout and keep the informative prefix
        pass the truncated sample to PPO/GRPO/GSPO
    else:
        continue until success or the normal turn limit
```

T³ 只包裹 rollout / trajectory construction；基础 RL 算法仍负责 log-prob、advantage、clipping、KL 等计算。

### 6.2 代理信号的统计鲁棒性

论文还分析 proxy 有偏差和噪声的情况。令真实单步潜势进展

\[
g_t=\Psi(b_t)-\Psi(b_{t+1}),
\]

可观测信号满足

\[
d_t=g_t+\beta_t+\xi_t,
\quad
|\beta_t|\le M_d,
\quad
\xi_t\sim\mathcal N(0,\sigma^2),
\]

并假设 BTR 外 \(g_t\ge\rho>0\)。若

\[
\Delta_{\min}<\rho-M_d,
\]

且

\[
\boxed{
 k(\rho-M_d-\Delta_{\min})^2
\ge
2\sigma^2\log(1/\delta)
}
\]

则在任意长度为 \(k\) 的非 BTR 片段上，误截断概率可被控制在 \(\delta\) 以下。直觉上，减小 proxy bias、减小阈值或增加窗口长度，都会降低误报；但更大的 \(k\) 也会延迟真正的截断。

## 7. 任务级 T³ 实例化

| 任务 | 隐含假设空间/进展量 | 截断规则 | 主实验窗口 |
|---|---|---|---:|
| **GuessNumbers (GN)** | 与历史反馈一致的候选数字集合 \(\mathcal H_t\)；\(d=|\mathcal H_t|-|\mathcal H_{t+1}|\) | 若新猜测落在当前可行集合之外（等价于没有合法收缩），立即截断 | \(k=1\) |
| **SituationPuzzles (SP)** | 与对话一致的潜在故事解释集合；集合通常不可枚举 | judge 连续返回 `Unknown`，视作没有产生有效约束 | \(k=5\) |
| **CircuitDecoding (CD)** | 仍与反馈一致的候选 Boolean circuits；\(d\) 为候选数减少量 | 候选空间连续若干轮不收缩 | \(k=3\) |
| **PreferenceEstimation (PE)** | 与反馈一致的偏好向量子空间；用显式估计 \(v_t\) 近似 | \(\mathrm{Sim}(v_{t+1},v^\star)-\mathrm{Sim}(v_t,v^\star)\) 连续为负 | \(k=2\) |
| **MovieRecommendation (MR)** | 与 PE 相同，最后把估计偏好迁移到未见电影 | 偏好估计持续偏离/不改善，然后截断交互阶段 | \(k=2\)（沿用 PE proxy） |

补充：

- SP 主实验使用 Qwen2.5-14B-Instruct 作为交互 judge；论文还测试了问题语义相似度 proxy。
- PE/MR 主实验的相似度 proxy 使用训练时可获得的真实偏好向量；这不是部署时必须的条件。附录给出完全不访问 ground truth 的版本：当预测向量在窗口内的平均变化量足够小，就判断 epistemic stalling。
- SP 的语义重复 proxy 以 E5-large-v2 计算当前问题与历史问题的 cosine similarity；阈值 \(\alpha=0.9,0.93,0.96\) 均做过消融。

## 8. 实验设计

### 8.1 实验问题

论文围绕以下问题展开：

1. T³ 是否在不同主动推理任务和不同 policy optimizer 上稳定有效？
2. 截断是否改善训练稳定性和 token efficiency，而不只是最终分数？
3. proxy 的窗口长度、阈值和误截断如何影响结果？
4. T³ 是否能跨任务分布、模型规模和架构泛化？
5. 观测到的优势 drift 是否与理论中的 BTR/GAE 分析一致？

### 8.2 任务与数据

论文使用 AR-Bench 与 Multi-Turn Puzzles 中的 5 个交互任务（4 个数据来源）：

| 任务 | 训练集 | 测试集 | 交互特点 |
|---|---:|---:|---|
| SituationPuzzles (SP) | 400 | 100 | 通过 yes/no 问题让 judge 约束故事解释 |
| GuessNumbers (GN) | 1,526 | 382 | 猜无重复数字，反馈为 \(xAyB\) |
| CircuitDecoding (CD) | 1,000 | 300 | 从候选 Boolean circuits 中识别隐藏电路 |
| PreferenceEstimation (PE) | 700 | 300 | 通过电影两两比较估计偏好向量 |
| MovieRecommendation (MR) | 700 | 300 | 将已估计偏好迁移到未见电影推荐 |

数据构造与难度控制：

- GN 改造为 \(a\) 位、从 \(b\) 个符号中无重复采样，候选数为
  \[
  P(b,a)=\frac{b!}{(b-a)!};
  \]
  首次猜测固定，以控制第一步随机性。
- CD 改变隐藏电路数与候选池大小，测试信息查询和候选淘汰能力。
- PE 控制参考电影数量、属性维度和偏好分布；MR 使用未见电影检验泛化。
- SP 的环境反馈不是规则程序，而由 Qwen2.5-14B-Instruct judge 根据 puzzle 的 surface/bottom 返回 `Yes/No/Unknown`。

### 8.3 模型、RL 算法与训练配置

**主模型：** Qwen2.5-7B-Instruct。

**比较方法：**

- Direct inference：o3-mini、Gemini-2.5-Pro、Qwen2.5-7B-Instruct；
- PPO；
- GRPO；
- GSPO；
- 每个 RL 方法分别比较 vanilla 与 `+ T³`。

**环境与奖励：**

- GN：终点 Exact Match（\(0/1\)）；
- SP：终点 F1-word / F1-char；
- CD、MR：终点 Exact Match；
- PE：预测偏好向量与真实向量的 cosine similarity，阈值为 0.88 时转成 Binary Similarity；
- 所有任务的奖励只在 trajectory terminal step 提供，正是为了测试 BTR 尾部对 outcome-based credit assignment 的影响。

**统一训练设置：**

- 每个任务训练 200 steps；
- actor learning rate \(1.0\times10^{-6}\)；
- FSDP、BF16；
- vLLM rollout，tensor parallel size = 1；
- 最大交互轮数：GN 10、SP 15、CD 10、PE 10、MR 5；
- SP sampling temperature = 1.0，GN = 0.6；所有数据 top-p = 0.95；
- PPO：GAE \(\lambda=1,\gamma=1\)，KL 系数 0.001，clip ratio 0.2；
- GRPO：每个 prompt 采样 5 个 response，其余 rollout/KL/clip 设置与 PPO 一致；
- GSPO：无 KL constraint，\(\epsilon_{\mathrm{low}}=0.0003\)，\(\epsilon_{\mathrm{high}}=0.0004\)。

硬件：GN/SP 使用单节点 8×H100；CD/PE/MR 使用单节点 8×B200。

### 8.4 评测指标

- GN、CD、MR：Exact Match；
- SP：word-level 与 character-level F1；
- PE：Binary Similarity；
- 训练过程额外观察 reward、response length、early-truncation ratio 和 token consumption；
- 主表还给出跨指标的平均 rank。

## 9. 实验结果

### 9.1 主结果

下表数值均按论文乘以 100，箭头表示相对于同一 vanilla RL 方法的**绝对百分点**提升。

| 方法 | CD EM | SP F1-word | SP F1-char | GN EM | PE Binary Sim | MR EM | Avg. rank |
|---|---:|---:|---:|---:|---:|---:|---:|
| PPO | 61.67 | 28.77 | 74.56 | 91.62 | 42.00 | 24.33 | 6.50 |
| PPO + T³ | **77.83** (+16.2) | **36.85** (+8.1) | **81.50** (+6.9) | **93.98** (+2.4) | **49.00** (+7.0) | **38.00** (+13.6) | 4.50 |
| GRPO | 79.33 | 36.46 | 83.73 | 61.26 | 51.67 | 12.00 | 5.50 |
| GRPO + T³ | **81.33** (+2.0) | **39.45** (+3.0) | **84.58** (+0.8) | **91.36** (+30.1) | **52.33** (+0.7) | **32.67** (+20.7) | 3.17 |
| GSPO | 77.67 | 36.63 | 82.17 | 96.07 | 59.00 | 14.67 | 4.33 |
| GSPO + T³ | **81.00** (+3.3) | **36.96** (+0.3) | 82.08 (−0.1) | **99.74** (+3.7) | **62.00** (+3.0) | **55.67** (+41.0) | **2.50** |

关键观察：

- 18 个 RL 对比指标中有 14 个获得非边际提升；
- 最大主结果增益是 GN 上 GRPO + T³ 的 **+30.1** 点；
- MR 上 GSPO + T³ 提升 **+41.0** 点；
- T³ 对不同 optimizer 都有效，但提升大小依赖任务和 proxy；
- 强模型的 zero-shot 在有限可枚举空间（GN/CD）上很强，但在连续或复杂空间（SP/PE）上，经过 RL 的 Qwen + T³ 仍有竞争力。

### 9.2 训练稳定性与 token efficiency

论文绘制 reward 与 response length 曲线：

- vanilla RL 的 reward 方差更高，部分任务在暂时收敛后会坍塌；
- 加 T³ 后 reward 通常更单调或接近单调，突降更少；
- T³ 可能在按“训练 step”计量时早期上升略慢，但每个 rollout 的平均 token 更少；
- CD 上 PPO + T³ 达到 reward 0.65 时，消耗的 token 约为 vanilla PPO 的 **66.4%**；
- GN 上 GSPO + T³ 达到 reward 0.96 时，消耗约为 vanilla GSPO 的 **76.3%**。

因此论文摘要所称的“最高约 34% token cost reduction”主要来自较早切除无效交互尾部，而不是减少模型参数或改变采样温度。

### 9.3 OOD 泛化

在 PPO 下测试分布变化：

- **CD：** 训练使用 2 个隐藏电路、10 个候选；测试把候选池扩展到 10–30、隐藏电路扩展到 2–4。T³ 在候选数 25 时提升 +10.8 点，在 3 个隐藏电路时提升 +15.0 点。
- **PE：** 训练参考集大小为 10，测试 \(S=5,10,15,20,25,30\)，并改变参考分数采样分布。\(S=20\) 时提升 +12.7 点；在 max-skew 分布下提升 +10.7 点。

代表性结果：

| OOD 设置 | Vanilla | +T³ | 提升 |
|---|---:|---:|---:|
| PE，参考数 \(S=20\) | 41.0 | 53.7 | +12.7 |
| PE，max-skew sampling | 50.7 | 61.3 | +10.7 |
| CD，候选数 \(S=25\) | 35.2 | 46.0 | +10.8 |
| CD，隐藏电路数 \(C=3\) | 60.3 | 75.3 | +15.0 |

### 9.4 截断条件消融

**窗口长度 \(k\)：**

- SP：从 \(k=3\) 到 \(k=5\) 持续改善，\(k=5\) 最好；\(k=9\) 过于宽松，收益消失；
- CD：\(k=3,4\) 最好，过小的窗口会过早截断仍有用的探索；
- PE：\(k=2\) 最好，窗口过大使停滞尾部保留太久。

**替代 proxy：**

- SP 的问题语义相似度 proxy（\(\alpha=0.9\)）可达到 39.44 F1-word，接近主设定的 39.45；
- CD/PE 的随机截断在合适概率下也可能有轻微提升，但过强会严重伤害性能；例如 CD 中随机 \(\beta=0.5\) 使 EM 从 61.67 降至 13.17；
- 这说明收益不只是来自“少走几步”，而在于 proxy 是否确实定位了 BTR。

**截断比例：**

- 无界/连续假设空间（SP、PE）中，较早且较稳定的截断比例往往有利；
- 有限、可枚举空间（CD）中，低到中等截断比例更好；过于激进会砍掉有价值的探索。

### 9.5 模型规模与架构

- Qwen2.5-3B 的增益有限；7B 与 14B 的增益明显；
- 论文推测较弱模型的 belief update error growth 更大，可能更快进入 BTR，导致即使截断也没有足够有用的前缀；
- 在 CD 上，LLaMA-3.1-8B-Instruct 的增益较小，Qwen2.5-7B 更明显，DeepSeek-R1-Distill-LLaMA-8B 的增益最大；
- 这些结果支持“模型的 belief-tracking 能力决定 T³ 可利用程度”的解释，但不构成对 \(m_\theta\) 的直接测量。

## 10. 理论的经验验证

### 10.1 Update-error growth

由于真实 belief 与 oracle Bayesian update 不可见，论文在 PE 上做近似验证：

- 用模型显式输出的偏好向量 \(w_t\) 定义
  \[
  \widehat\Psi_t=\lVert w_t-w^\star\rVert_2^2;
  \]
- 用线性 Gaussian update 作为 \(B^\star\) 的 surrogate；
- 以
  \[
  \widehat c_\theta
  =d(w_{t+1})-d(w'_{t+1})
  \]
  近似 update error；
- 收集超过 150k 个 Qwen2.5 rollout 样本，在高潜势区域对 lower envelope 做线性拟合。

得到的拟合斜率为正：

- Qwen2.5-7B：\(\widehat c_\theta\approx0.0969\widehat\Psi-3.0478\)；
- Qwen2.5-32B：\(\widehat c_\theta\approx0.4655\widehat\Psi-1.5158\)。

这与“偏离越大，更新误差下界越高”的假设一致，但仍是 proxy-level evidence。

### 10.2 Advantage drift

论文在失败 rollout 上只分析前 500 个 token 的 GAE：

- 不截断时，早期 token advantage 出现明显负向 drift；
- T³ 后早期 advantage 整体抬高；
- 人为延长无信息尾部时，早期 advantage 被压得更低；
- 更激进的截断（较小的 \(k\)）能得到更干净的前缀 advantage。

### 10.3 误截断的代价

论文也明确验证了 false-positive truncation 的反面影响：在最终成功、确实包含有效未来信号的 rollout 上，强制在第 3 轮截断的概率越高，早期动作的 GAE 越低。因此 T³ 的关键不是“尽量截短”，而是准确区分：

\[
\text{无信息 BTR tail} \quad\text{vs.}\quad \text{仍在探索的有效 future}.
\]

### 10.4 不访问 ground truth 的 T³

PE 附录给出一个更适合真实部署的 proxy。令模型显式输出的估计为 \(\hat v_t\)，定义窗口内平均更新量：

\[
\mathrm{stall}_t
=\mathbf 1\left[
\frac1k\sum_{j=t-k}^{t-1}
\lVert\hat v_{j+1}-\hat v_j\rVert_2
<\varepsilon
\right].
\]

\(\varepsilon\) 从离线 rollout 的更新量分布中取 60%、75%、85% 分位数。PE 上 PPO 的 Binary Similarity 为：

- vanilla：44.33；
- ground-truth-free T³：44.33（60% 分位数）、50.67（75% 分位数）、49.00（85% 分位数）；
- 主实验 ground-truth proxy：49.00。

说明 T³ 原则并不必然要求训练时访问真实答案，关键是找到能反映 epistemic stalling 的可观测信号。

## 11. 方法评价、局限与可迁移启示

### 11.1 最有价值的观点

1. **把长轨迹失败拆成“有信息前缀 + 有害尾部”。** 这比把整条失败轨迹视作一个不可分割的负样本更适合主动推理。
2. **BTR 提供了连接 belief tracking 与 RL credit assignment 的中间概念。** belief 偏离不是只影响 inference，也会改变训练梯度。
3. **T³ 是 optimizer-agnostic 的 rollout wrapper。** 只要环境能提供进展 proxy，就可包在 PPO、GRPO、GSPO 外部。
4. **截断强度必须匹配假设空间结构。** 连续/无界任务可能需要更积极地切尾；有限候选任务要避免把探索过早砍掉。
5. **方法可以节省 token。** 性能提升与计算效率提升来自同一个机制：不再生成已经无法提供信息的尾部。

### 11.2 局限

- 理论中的 \(s^\star\)、真实 belief、BTR 阈值 \(U\) 都不可直接观察；Theorem 1/2 是在较强假设下的充分条件和上界，不是通用收敛定理。
- 实践 proxy 仍可能需要任务级结构；主实验的 PE/MR proxy 访问真实偏好向量，虽有 ground-truth-free 附录实验，但不代表所有任务都容易构造无监督 proxy。
- 误截断会删除真正有价值的后续探索，导致 advantage 下降；\(k\)、\(\Delta_{\min}\)、语义相似度阈值需要校准。
- 任务主要是受控的交互式 benchmark，SP 还依赖一个 LLM judge；在开放世界工具调用、非平稳环境和 reward hacking 下，proxy 可靠性仍需验证。
- T³ 处理的是“进入陷阱后的尾部污染”，并没有直接提升模型的 belief representation；如果模型在第一步就无法产生有效信息，截断也无从挽救。

### 11.3 对 RL 系统实现的启示

若将 T³ 接入通用 RL 框架（例如 SkyRL），建议把以下语义显式区分：

- `terminated`：环境真正完成或任务失败；
- `truncated_by_belief_trap`：T³ 检测到停滞而提前结束；
- `progress_signal` / `truncation_window`：用于审计 proxy 和调节 \(k\)。

尤其要在 advantage/value bootstrap、response mask、turn mask 和 terminal reward 之间保持一致：T³ 的理论收益来自移除尾部，而不是简单把被截断样本当成普通成功或普通失败。训练日志还应记录截断比例、触发 turn、保留 token 数和最终 outcome，才能区分“更少 token”与“真正更好的 credit assignment”。

## 12. 总结

T³ 的完整逻辑可以压缩为：

\[
\begin{aligned}
&\text{LLM 的 belief update 误差随偏离扩大}\\
&\Rightarrow \text{轨迹进入 expected progress 非正的 BTR}\\
&\Rightarrow \text{长尾通过 GAE 污染早期探索的 credit}\\
&\Rightarrow \text{用任务进展停滞 proxy 近似 BTR 入口}\\
&\Rightarrow \text{提前截断，只用信息前缀更新策略}.
\end{aligned}
\]

它的主要贡献不是一个新的 policy objective，而是指出：在部分可观测、多轮主动推理中，**trajectory boundary 本身就是 credit assignment 的控制变量**。
